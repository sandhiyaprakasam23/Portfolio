## 🚀 Running Locally

```bash

npm install

# 2. Start development server
npm run dev

# 3. Build production bundle
npm run build

# 4. Preview production build
npm run preview
```

## 🌐 Deploying to Vercel or Netlify

1. Push this folder to your GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: sandhiya 3d developer portfolio"
   git branch -M main
   git remote add origin https://github.com/sandhiyaprakasam23/portfolio.git
   git push -u origin main
   ```
2. On **Vercel** (`vercel.com`) or **Netlify** (`netlify.com`), click **Import Repository**.
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**!
